# Youtube Downloader

**Download youtube videos - OR - Download youtube playlists.**

Provide a link to an individual youtube video or link to a full playlist of videos and download them for offline viewing. Youtube to MP4 and Youtube to MP3.

This is essentially a user-friendly desktop wrapper for YT-DLP.


.<sub><sub> Youtube2MP4, Youtube2MP3, Youtube2MKV, Youtube Downloader, Youtube Playlist Downloader </sub></sub>
